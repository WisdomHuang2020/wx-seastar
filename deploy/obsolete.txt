# 废弃文件清单
#
# 用途：CI 部署是**增量覆盖**，不会删除服务器上已有、但仓库里已移除的文件。
#       长期下来 web 根会积累废弃资源（旧版本图片、改名后的旧文件等），
#       既占空间，也可能让旧版页面/资源仍能被公网访问到。
#
# 机制：deploy-lighthouse.yml 的部署步骤会逐行读取本文件，
#       在服务器上删除对应路径（相对 web_root），**删除前该路径会先进入
#       部署前的整站备份**，所以是可恢复的。
#
# 规则：从仓库移除任何**已发布**的静态文件时，务必把它的路径补到这里。
#       注释用 # 开头；空行忽略。
