# SEA☆STAR 实益达 官网原型 — 使用说明

照明灯具企业官网高保真 HTML/CSS 原型（三大业务线：ODM 设计 / 通用照明 / 植物灯具）。

## 预览方式

**双击 `index.html` 即可在浏览器打开**，无需服务器、无需联网。
所有样式、图标、插画均为内联实现，零外部依赖（无 CDN、无字体文件、无图片 URL）。

## 文件结构

```
├── index.html        首页（深色 Hero 光锥 + 三业务线 + 实力数据 + 精选产品 + 技术带 + CTA）
├── odm.html          ODM 设计页（明底创意 · 五步设计流程时间轴 · 案例网格 · 研发实力）
├── lighting.html     通用照明页（场景 Hero · 产品筛选 Tab · 应用场景切换 · 认证墙）
├── grow-light.html   植物照明页（暗底技术密度最高 · 光谱曲线 SVG · 参数表 · 资源下载）
├── about.html        关于我们（品牌故事 · 发展历程 · 团队价值观 · 工厂产能）
├── contact.html      联系我们（询价表单 + 联系信息卡 + 地图占位）
├── styles.css        共享样式表（含 DESIGN.md 全部设计令牌 :root{}）
├── js/app.js         共享交互脚本（导航毛玻璃 / 抽屉 / 滚动入场 / Tab / 计数 / 表单）
└── DESIGN.md         设计系统规范（输入依据）
```

## 技术要点

- **设计系统**：严格消费 `DESIGN.md` 的令牌（色彩、排版、间距、圆角、光效、动效），未自行发明色值。
  - 品牌主色暖琥珀金 `#F5A623`；深色主底 `#0F0F1A`；页面主底 `#FAFAFA`。
- **核心光效**：glow-accent（按钮）、glow-product（产品发光）、beam-cone 光锥（Hero）、halo-bottom（卡片底部柔光）、光谱绘制。
- **动效语言**：点亮 Ignite / 呼吸 Breathe / 流光 Sheen / 光谱绘制 Trace / 滚动联动（IntersectionObserver），全部尊重 `prefers-reduced-motion`。
- **响应式**：Mobile <640 / Tablet 640–1024 / Desktop >1024，`clamp()` 流体排版，技术表格移动端横向滚动。
- **排版**：标题 Light 字重 + 负字距（不用 Bold）；数据区 JetBrains Mono 等宽；不加粗强调。
- **无障碍**：语义化标签、面包屑、`aria-label`、`sr-only` 说明、焦点态可见。

## 原型说明

- 页面内容为**示例内容**（专业照明行业语境），统计数据、产品参数使用 `—` 占位或标注灰色说明，未编造具体数字。
- 光谱曲线、图标、灯具剪影均为手工内联 SVG，用于展示可视化能力，非实测数据。
- 表单为前端演示，提交不会真实发送；地图为 CSS/SVG 占位。

## 已知需质量审查关注点

1. `lighting.html` 的筛选 Tab 为纯前端切换（不刷新），已通过 `data-tabs` / `data-panel` 机制实现。
2. `grow-light.html` 参数表数值采用 `—` 占位（原型阶段不编造数据），正式交付需替换为真实规格。
3. 色温/PPF 等专业指标文案为行业通用表述，建议由业务方复核术语准确性。
4. 移动端抽屉菜单为全屏深色，菜单项 stagger 淡入。
